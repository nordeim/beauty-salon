## The lesson (recorded in SKILL v1.10.0 + PAD)

**Focus parity is invisible to every census that reads the settled DOM — and to every interaction census that reads only text/state.** The ring only exists on `:focus`/`:focus-visible`; twelve prior sessions' instruments never read computed styles while focused. And **trap 9 sharpens the session-7 lesson: class-string parity does NOT imply computed parity** — when two utilities set the same custom property under different pseudo-class variants, the v3 and v4 engines can pick different winners from byte-identical class strings; the only pin that holds is the computed outcome, read while focused. Plus the measurement discipline: freeze transitions before synchronous reads (`page.addStyleTag('* { transition: none !important }')`) — a mid-transition read captures the pre-transition value, which cost the first RED run two false guard failures.
